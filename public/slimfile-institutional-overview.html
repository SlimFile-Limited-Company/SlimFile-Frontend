The SlimFile Compression API
api.slim-file.com
Developer Infrastructure

One API. Infinite integration possibilities.

The SlimFile API is a RESTful HTTP interface that gives developers and institutions direct programmatic access to SlimFile's entire compression and conversion engine. Integrate it once into your system and your platform gains the full power of SlimFile — without your users ever leaving your product.

How it works

Send a file to the API endpoint with your API key. SlimFile compresses or converts it on the server and returns the processed file or a download link — all within seconds. No file is stored permanently. All transfers are encrypted over HTTPS.

REST API — Compress a PDF
# POST to compress a PDF
curl -X POST https://api.slim-file.com/v1/compress \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "file=@report.pdf" \
  -F "quality=80" \
  --output compressed_report.pdf
JavaScript SDK — Compress & Summarize
import SlimFile from '@slimfile/sdk';

const sf = new SlimFile({ apiKey: 'YOUR_KEY' });

// Compress a PDF
const result = await sf.compress.pdf(file, { quality: 80 });

// AI Summarize a document
const summary = await sf.ai.summarize(file);
